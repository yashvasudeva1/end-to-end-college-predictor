How to Read This

  • Train vs Test gap: If test MAE is much higher than train MAE, the model is overfitting - it memorises training data instead of learning patterns.
  • R² close to 1: The model explains most cutoff variation. A large drop from train to test R² signals overfitting.
  • Good fit: Train and test metrics are close, and test R² remains high - the model generalises well.
  • The model is best used for relative comparison between colleges rather than exact rank prediction.

Methodology & Notes

Technical details about the predictive pipeline, feature engineering, and model approach.

Model

XGBoost Regressors trained separately for Opening Rank and Closing Rank prediction.

Approach

  • Learns year-to-year cutoff movement from 5 years of official JoSAA data.
  • Uses lag and rolling features (moving averages, standard deviations) to capture temporal patterns.
  • Predicts numeric cutoffs instead of categorical labels for higher granularity.
  • Encodes categorical variables (institute, branch, quota, seat type, gender) using label encoding.

Why Trends Matter

  • Sudden rank jumps indicate changing demand for specific branches or institutes.
  • Stable trends give safer counselling signals and more reliable predictions.
  • Round-wise analysis reveals whether later rounds historically benefit candidates.

Data Pipeline

  • Data extracted from official JoSAA website across years 2021–2025.
  • Cleaned for duplicates and null values.
  • Feature engineering adds rank gap, rank ratio, rolling statistics, and lag features.
  • Train-test evaluation ensures model generalisation before deployment.

Disclaimer

This tool provides probabilistic guidance, not guarantees. JoSAA policies, seat matrices, and application patterns can change each year. Use this as one input in your decision-making process alongside official counselling data.
